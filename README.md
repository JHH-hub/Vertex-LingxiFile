# 灵犀文件管家 - LingXi File Manager

一个现代化的本地文件管理工具，专为游戏开发者和内容创作者设计，集成了AI智能重命名、文件标签管理、重复检测等实用功能。

## 🚀 快速开始

### 系统要求
- Windows 10/11
- Python 3.8+
- 推荐：支持AI功能的API密钥（可选）

### 安装步骤
1. 下载本项目到本地
2. 双击运行 `run.bat`
3. 自动安装依赖并启动服务
4. 浏览器自动打开 `http://127.0.0.1:7870`

### 手动启动（备用）
```bash
cd "F:\10-自制提效工具\灵犀文件管家"
pip install -r requirements.txt
python server.py
```

## 📋 功能特性

### 核心功能
- **📁 文件浏览**：树形目录 + 网格/列表/详情三种视图
- **🎨 智能预览**：图片、PDF、视频、Spine动画、代码文件预览
- **🤖 AI重命名**：基于内容智能生成语义化文件名
- **🔍 全文搜索**：支持文件名和内容语义搜索
- **🏷️ 标签系统**：自定义标签 + AI自动打标签
- **⭐ 收藏管理**：快速访问常用文件和目录

### 游戏开发专用
- **🎮 Spine资源识别**：自动识别.spine文件及相关资源
- **📦 重复文件检测**：基于哈希值检测重复文件
- **🔄 批量操作**：支持多文件同时重命名、移动、复制
- **📊 操作历史**：完整操作记录，支持撤销

### AI增强功能
- **智能命名**：根据图片内容、代码结构自动推荐文件名
- **内容描述**：AI自动生成文件内容摘要
- **整理建议**：AI分析目录结构，给出整理方案
- **批量处理**：一键处理多个文件的AI重命名

## ⚙️ 配置说明

### AI配置（可选但推荐）
首次启动后，点击右上角设置图标配置AI服务：

**支持的AI服务商：**
- OpenAI (GPT-4o, GPT-3.5)
- 智谱AI (GLM-4)
- DeepSeek (DeepSeek-V3)
- 月之暗面 (Moonshot)
- 通义千问 (Qwen)
- 本地Ollama

**配置示例：**
```
API Base URL: https://api.openai.com/v1
API Key: sk-...
模型: gpt-4o-mini
视觉模型: gpt-4o-mini
```

### 根目录配置
在设置中添加需要管理的根目录：
- 游戏项目目录（如：`F:\05 中式微恐（游戏项目）`）
- 美术资源目录
- 代码库目录

## 🎯 使用指南

### 基本操作
- **导航**：左侧目录树 + 面包屑导航
- **选择**：单击单选，Ctrl+单击多选，Shift+单击范围选择
- **操作**：右键菜单或顶部工具栏
- **预览**：点击文件在右侧面板预览

### 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+K` | 聚焦搜索框 |
| `Enter` | 打开选中项 |
| `F2` | 重命名 |
| `Delete` | 删除到回收站 |
| `Ctrl+A` | 全选 |
| `Ctrl+Z` | 撤销 |
| `Backspace` | 返回上级 |

### AI重命名流程
1. 选择需要重命名的文件（支持多选）
2. 点击工具栏「🤖 AI重命名」
3. 预览AI推荐的新文件名
4. 确认应用更改

## 🔧 技术栈

### 后端
- **框架**：Flask + Flask-SocketIO
- **数据库**：SQLite（轻量级，无需额外安装）
- **文件操作**：Python标准库 + send2trash（安全删除）
- **AI集成**：OpenAI兼容API

### 前端
- **界面**：原生HTML/CSS/JavaScript
- **设计**：现代化暗黑主题
- **交互**：实时WebSocket通信
- **图标**：SVG矢量图标

## 🐛 故障排除

### 常见问题

**Q: 启动时报端口占用错误**
A: 修改server.py中的端口号（默认7870），或关闭占用该端口的程序

**Q: AI功能无法使用**
A: 检查网络连接和API密钥配置，确保服务商可用

**Q: 文件操作权限不足**
A: 以管理员身份运行，或检查文件/目录权限

**Q: 缩略图不显示**
A: 清空_data/thumbs/目录重新生成缓存

### 日志查看
启动时控制台会显示详细日志，错误信息会在此显示。
